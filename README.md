 ## CodeAlpha CGPA Calculator

 ## About
This project is a simple CGPA Calculator developed in C++ as part of the CodeAlpha C++ Programming Internship.

## Features
- Takes the number of courses
- Takes grade points and credit hours
- Calculates total grade points
- Calculates total credits
- Displays the final CGPA

## Technology Used
- C++

## Formula
CGPA = Total Grade Points / Total Credit Hours
